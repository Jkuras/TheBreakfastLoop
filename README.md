# TheBreakfastLoop
Midi controllers, IO Boxes, and Audio Devices for The Breakfast Loop, an experimental synth instrument.

#Flight Controller MIDI
Converting a 4-axis flight controller to act as a drone synth controller. In Progress.

#Guitar Hero MIDI
Converting a guitar hero (PS2) controller to control either a Volca Sample or act as a pentatonic-only midi note controller

#Orgalorgan
Converted a 90s-2000s Lowrey Organ to a midi controller using existing circuitry, button arrays, and ICs as much as possible.

#Orgalorganagain
Converted a 50s-80s Lowrey 3-manual organ to a midi controller to house a 4-person synth group. One code file is altered and spread between 3 arduinos, one per keyboard, with intention to combine into one and use MIDI channels to reduce internal wiring and power requirements.
